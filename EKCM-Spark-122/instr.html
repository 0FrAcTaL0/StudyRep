ВВЕДЕНИЕ

Настоящая инструкция предназначена для изучения и правильной эксплуатации электронной клавишной вычислительной машины ЭКВМ «Искра-122».
Инструкция содержит следующие разделы:
  • подготовка к работе;
  • техническое обслуживание;
  • приложения.

1. ПОДГОТОВКА К РАБОТЕ

1.1. Общие указания

1.1.1. ЭКВМ «Искра-122» в данном проекте представлена программным эмулятором, работающим в браузере.

1.1.2. Запуск проекта разрешается выполнять только через HTTP/HTTPS-сервер. Файлы index.html и instr.html не следует открывать напрямую как локальные файлы через file://. Это необходимо для корректной загрузки связанных ресурсов проекта (CSS, JavaScript и изображений).

1.1.3. После запуска сервера откройте в браузере страницу index.html. Например, при использовании локального статического сервера адрес может иметь вид http://localhost:8000/index.html. Конкретный порт зависит от выбранного сервера.

1.1.4. Для работы требуется современный браузер с поддержкой JavaScript. Скрипт калькулятора подключается из index.html, а кнопка «Инструкция» открывает instr.html в новой вкладке.

1.1.5. Перед началом вычислений убедитесь, что страница калькулятора полностью загрузилась. При загрузке эмулятор находится в выключенном состоянии, а клавиши калькулятора до включения не обрабатываются.

1.1.6. Для включения эмулятора установите экранный переключатель питания в верхнее положение. При включении состояние вычисления сбрасывается, после чего можно работать с клавиатурой калькулятора.

1.1.7. Для завершения работы установите экранный переключатель в нижнее положение. После выключения элементы клавиатуры не выполняют вычислений.

1.2. Указания по работе с эмулятором

1.2.1. Все действия оператора выполняются непосредственно в окне браузера: переключатель питания, кнопки клавиатуры, кнопки памяти и переключатель точности являются интерактивными элементами страницы.

1.2.2. Не изменяйте файлы проекта во время работы страницы, если цель — проверка штатного поведения эмулятора. При необходимости изменить код после редактирования следует перезагрузить страницу через сервер.

1.2.3. Если после изменения файлов браузер показывает старую версию скрипта или страницы, выполните обычную перезагрузку страницы и при необходимости очистите кэш браузера.

1.2.4. Печатная операция не использует физический принтер калькулятора: кнопка «ˆ» вызывает стандартное диалоговое окно печати браузера.

1.3. Ввод эмулятора в работу

1.3.1. Запустите HTTP/HTTPS-сервер из каталога проекта. Не запускайте проект двойным щелчком по index.html или instr.html.

1.3.2. В браузере перейдите на адрес, предоставленный сервером, и откройте index.html. Убедитесь, что отображаются корпус калькулятора, табло, клавиатура, регистры памяти и флаги.

1.3.3. Нажмите экранный переключатель питания. При включении JavaScript переводит эмулятор в рабочее состояние, очищает текущее вычисление и отображает начальное состояние табло.

1.3.4. При необходимости нажмите «CK» для сброса текущего вычисления. Кнопка «CK» очищает состояние текущего вычисления и флаги; значения регистров памяти A1–A5 и выбранная точность при этом сохраняются.

1.3.5. Выберите точность вычислений кнопками «B», «13», «11», «9», «7», «5» или «3». В режиме «B» ограничение значащих цифр результата не устанавливается; остальные положения задают количество значащих десятичных разрядов результата последующих вычислений.

1.3.6. Проверьте работоспособность эмулятора несколькими контрольными вычислениями из приложения 1. Ввод выполняйте кликами по кнопкам интерфейса; десятичная часть вводится кнопкой «.», а не физической клавишей с запятой.

1.3.7. Если результат отличается от ожидаемого, сначала проверьте выбранную точность, последовательность нажатий, состояние памяти и наличие флага OF. Затем перезагрузите страницу и повторите проверку.

1.3.8. Окончанием сеанса работы считается выключение экранного переключателя и, при необходимости, закрытие вкладки браузера. Сервер можно остановить после завершения работы со всеми страницами проекта.

1.4. Порядок работы

1.4.1. После включения эмулятора число вводится нажатием экранных кнопок «0»–«9». Для дробного числа используется кнопка «.». При вводе правильной дроби после «0» следующая цифра автоматически начинает дробную часть, например последовательность «0», «5» формирует 0,5.

1.4.2. Для отрицательного числа сначала введите число, затем нажмите кнопку «/-/». Положительный знак отдельно не вводится.

1.4.3. При ошибке ввода используйте «CK». Кнопка сбрасывает текущее вычисление, но не сбрасывает выбранную точность и содержимое регистров памяти.

1.4.4. Арифметические операции выполняются кнопками «+», «−», «•» и «÷». После выбора операции введите следующий операнд и нажмите «=». Результат отображается на табло.

1.4.5. Кнопка «ģ» выполняет обратное деление, то есть операцию 1/x над текущим числом. Кнопка «√» извлекает квадратный корень. Кнопка «/» выполняет выделение целой части без округления.

1.4.6. Возведение в степень выполняется кнопкой «↑». Повторные последовательные нажатия этой кнопки повышают степень: n последовательных нажатий соответствуют степени n+1 от исходного числа. Любое другое действие прерывает такую цепочку.

1.4.7. Скобки «(» и «)» поддерживают вложенные выражения и задают приоритет операций. При нажатии «=» незакрытые скобки автоматически закрываются, после чего вычисляется итоговое выражение.

1.4.8. Точность задается кнопками «B», «13», «11», «9», «7», «5», «3». Она влияет на результаты последующих вычислений, а не пересчитывает уже отображенное значение. Например, для 8÷9 положения 13, 11, 9, 7, 5 и 3 дают соответственно 0,8888888888889; 0,88888888889; 0,888888889; 0,8888889; 0,88889; 0,889.

1.4.9. Табло содержит знак и 16 цифровых разрядов. При превышении доступного диапазона устанавливается флаг переполнения OF; дальнейшая работа с клавиатурой и памятью до сброса не выполняется.

1.4.10. Регистры A1–A5 доступны через одноименные кнопки. Если регистр пуст, нажатие соответствующей кнопки сохраняет в него текущее число. Если регистр уже содержит число и на экране есть активное значение, происходит обмен текущего значения с содержимым регистра. Если активного значения на экране нет, содержимое регистра вызывается на экран.

1.4.11. Кнопки «2» и «3» в панели памяти не являются обычными цифровыми кнопками: они добавляют текущее значение с экрана соответственно в регистры A2 и A3. Поэтому для накопления сумм используйте именно кнопки с кружками в панели памяти, а для обычного ввода цифр — кнопки цифровой панели.

1.4.12. Если A1 уже содержит число и после выбора арифметической операции второй операнд явно не введен, при нажатии «=» эмулятор использует значение A1 как второй операнд, не изменяя сам регистр A1.

1.4.13. Кнопка «ˆ» запускает печать средствами браузера (window.print()).

б) выборка соответствующего регистра памяти, если перед этим следовала любая из остальных операций «+», «-», «•», «÷», «ģ», 2, 3, «СК», «А1», «А2», «А3», «А4», «А5», кроме операции «(», которая не оказывает влияния на правила засылки и выборки.

Автоматическая выборка из регистра памяти А1 на месте пропущенного операнда осуществляется, если после нажатия одной из клавиш операций «+», «-», «•», «÷», «ģ» следует нажатие любой из этих же клавиш или клавиши «)», «=».

1.4.8. Гашение ранее записанного числа во всех регистрах памяти машины производится автоматически при засылке в них нового числа.

1.4.9. Сброс всех регистров, кроме регистров памяти, осуществляется последовательным нажатием клавиш «=» и «СК».

1.4.10. Признаком переполнения разрядной сетки машины является высвечивание запятых на цифровом индикаторе после каждого десятичного разряда; при этом для приведения машины в рабочее положение нажмите клавишу «СК» (переполнение наступает в том случае, если количество целых чисел результата больше 16).

1.4.11. Во избежание ошибок в вычислениях каждому новому расчету (или возобновлению расчетов после ошибки) должно предшествовать последовательное нажатие клавиш «=» и «СК».

1.5. Техническое обслуживание браузерного эмулятора

1.5.1. Основное условие корректной работы — запуск проекта через HTTP/HTTPS-сервер. Открытие страниц напрямую через file:// не является штатным способом запуска и не должно использоваться.

1.5.2. При изменении index.html, script.js, таблиц стилей или изображений повторно загрузите страницу через сервер, чтобы браузер использовал актуальные файлы проекта.

1.5.3. При подозрении на ошибку сначала проверьте консоль разработчика браузера и убедитесь, что script.js, CSS и изображения загружаются без ошибок. После этого повторите контрольный пример.

1.5.4. Для воспроизводимой проверки рекомендуется каждый новый сеанс начинать с включения эмулятора, нажатия «CK» и явной установки требуемого положения точности.
